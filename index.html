It answers on your desktop, not in a browser tab.

Chatty sits on your wallpaper. Type in the bar at the bottom and the answer appears in place — nothing opens, nothing steals your focus. Behind it is any OpenAI-compatible model you like, including one running on your own machine.

Chatterbot 2000 is a Rainmeter skin, not a standalone program. You need Rainmeter installed first — free, open source, Windows only, 4.5 or newer. Without it, the download will not run.

    Getting it running

    1. Install Rainmeter. rainmeter.net — free, open source, Windows only. Nothing here works without it.
    2. Download the .rmskin and double-click it. Rainmeter's own installer does the rest.
    3. Click the gear and pick a provider. The status light starts red because nothing is configured yet. Choose one and it turns green.

    What it does

    It looks things up, then shows its work

    The model decides when it needs to search. Results come back as clickable source pills under the answer, so you can check where a claim came from instead of taking its word for it.

    Weather is real measured conditions and a three-day forecast from Open-Meteo — no key, ever. And the date goes into every request, so it will not hand you a two-year-old result and call it the latest.

    Any model, including your own

    DeepSeek, OpenAI, Groq, OpenRouter, Together — or Ollama and LM Studio running locally, which need no API key at all. Pick a preset and it fills in the base URL and a sensible default model.

    Keys are stored on your disk and displayed masked, so a screenshot can't leak one.

    Gets out of the way

    Click the title and it folds down to its header. Click again and the conversation is still there. When you want the desktop back, you take it back.

    Where your words go

    • With a local provider — nowhere. Point it at Ollama or LM Studio and there is no key, no account, and nothing leaves the machine.
    • With a cloud provider, your messages go to that provider and nowhere else. There is no server in the middle, because there is no server.
    • Weather is looked up by a place name you typed — never your location.
    • Your keys live in @Resources\config.json on your own disk. That file is excluded from the package and from version control.

    There is no telemetry in the skin. This website counts visits with Google Analytics, which is a different thing in a different place, and it is only fair to say so.

    Web search is optional and uses Tavily — the free tier is 1,000 searches a month and needs no card. Without a key there is a DuckDuckGo fallback that works for a handful of queries and then serves a CAPTCHA; when that happens Chatty says so plainly rather than pretending.

    The skin is a shell. Somebody else can inhabit it.

    Open settings, click PERSONA, and each click loads the next installed pack. The header name, the prompt in the input bar, the face and the personality all change together.

    A pack is one self-contained folder — a persona.json and a face.png. Installing one is a folder copy; removing one is a delete. Nothing is scattered into shared folders, so a pack you were handed can be thrown away cleanly.

    Chatty ships as a pack like any other, so the built-in character is not a special case in the code and the cycle always has somewhere to return to.
